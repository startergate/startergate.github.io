<h2 id="인터랙티브-스토리텔링의-이점">인터랙티브 스토리텔링의 이점</h2>
<ul>
<li>게임에 더 감정적으로 몰입하게 함</li>
<li>캐릭터에 대한 애착 생성</li>
<li>의미를 부여해줌</li>
<li>플레이어가 게임을 끝까지 플레이하게 함<ul>
<li>게임을 시작한 플레이어의 20~25%의 플레이어만 게임을 완료함</li>
<li>디트로이트: 비컴 휴먼은 61.7%를 기록함</li>
</ul>
</li>
<li>경험을 기억에 남게 함</li>
</ul>
<p>인터랙티브 스토리텔링은 왜 특별한가?</p>
<ul>
<li>유일하게 청중과 함께할 컨텐츠를 만드는 방법</li>
<li>플레이어는 보다 높은 인터렉티비티를 가지고 참여할 수 있어야 함</li>
</ul>
<h2 id="이러한-경험은-어떻게-만들어지는가">이러한 경험은 어떻게 만들어지는가?</h2>
<ul>
<li>플레이어와 함께 스토리를 풀어야 함</li>
<li>컷신이 아니라 게임 플레이를 통해서 스토리를 풀어야 함</li>
<li>사실을 은폐하는게 아니라 결과가 있어야 함<ul>
<li>실질적으로 결과에 변화를 줄수 있다는 인식을 줘야 함</li>
</ul>
</li>
</ul>
<p>선형적인 스토리와 인터랙티브 스토리의 차이</p>
<ul>
<li>선형적인 스토리는 공간과 시간의 2차원만 존재함</li>
<li>인터랙티브 각본은 공간 시간 인터랙티비티의 3차원이 존재함</li>
<li>더 깊이가 생김</li>
<li>선형적인 스토리보다는 훨씬 복잡해짐</li>
<li>캐릭터가 플레이어의 선택에 따라서 달라질 수 있음</li>
<li>게임이나 인터랙티브 스토리에서는 하나의 작품이 여러 의미를 가질 수 있음</li>
<li>각본이 훨씬 김<ul>
<li>디트로이트 비컴 휴먼은 4000 페이지였음</li>
</ul>
</li>
<li>=&gt; 새로운 작법이 플요함</li>
</ul>
<p>내러티브 공간</p>
<ul>
<li>내러티브 공간의 경계를 정해야 함</li>
<li>그 공간 안에서 플레이어들이 스토리를 만들어감</li>
</ul>
<p>트리 구조 바탕의 인터랙티브 스토리</p>
<ul>
<li>무작정 분기를 나누고 스토리를 만드는건 불가능함</li>
<li>적당히 쳐내고 스토리를 만들수 있어야 함
<img src="https://raw.githubusercontent.com/startergate/Conferences/master/g-con/2022/day-1/statics/image-1.jpg" alt="" loading="lazy" /></li>
<li>디트로이트같은 게임에는 수천개의 변수가 있음</li>
<li>모든 것이 일관성을 가지게 해야하고 이게 제일 어려움</li>
</ul>
<p>선택과 결과</p>
<ul>
<li>항상 염두에 두어야 함</li>
<li>도덕적인 딜레마</li>
<li>맥락과 잃게될 것이 명확하게 주어져야 함</li>
<li>흑백이 되는게 아니라 회색의 영역이 되어야 함<ul>
<li>모호한 질문을 하면 플레이어가 가치관에 따라서 결정을 내리게 됨</li>
</ul>
</li>
<li>내가 누군지에 따라서 달라질 수 있는 질문을 물어봐야 함</li>
<li>그래야 사람들이 게임에 흥미를 느낌</li>
</ul>
<p>플레이어의 결정이 중요하다는 느낌을 줘야 함</p>
<ul>
<li>메인 캐릭터가 죽을 수 있어야 함</li>
<li>퀀틱 드림에서는 내러티브 하나가 종료되는 것으로</li>
<li>조연 캐릭터도 죽을 수 있어야 함</li>
<li>이런 선택을 게임 초반에 주어서 결정이 중요하다는 느낌을 줌</li>
<li>덜 선택하는 분기도 포용해야 함</li>
</ul>
<p>티켓 순간과 도덕적 딜레마</p>
<ul>
<li>답이 정해지지 않은 질문</li>
<li>모든 답이 타당해야 함</li>
<li>게임을 통해서 나는 누구인가 어떤 가치관을 가지고 있는지 보여준다</li>
<li><img src="https://raw.githubusercontent.com/startergate/Conferences/master/g-con/2022/day-1/statics/image-2.jpg" alt="" loading="lazy" /></li>
</ul>
<p>대본은 영화 각본과 비슷</p>
<p>이미지를 넣어서 생각을 구체적으로 표현</p>
<p>드로잉을 넣어서 팀원들이 더 잘 이해할 수 있게 함</p>
<p>하나의 텍스트 문서로 스토리를 표현하는건 불가능했음</p>
<p>트리 구조와 다이어그램으로 모든 변수를 반영했는지 관리함</p>
<p>수많은 차트를 통해서 구조를 잡아감</p>
<p>퀀틱 드림에서는 게임은 현실적인 문제를 다룰수 있다고 생각함</p>
<p>사회적 문제를 다루기 위해서 2년간 연구함</p>
<p><img src="https://raw.githubusercontent.com/startergate/Conferences/master/g-con/2022/day-1/statics/image-3.jpg" alt="" loading="lazy" /></p>
<ul>
<li>존중하며 다뤄야함</li>
<li>사람들에게 생각한 거리를 던져줌</li>
</ul>
<h2 id="인터랙티브-스토리텔링의-도전">인터랙티브 스토리텔링의 도전</h2>
<ul>
<li>모든 분기가 타당해야 함</li>
<li>모든 것이 일관성이 있어야 함</li>
<li>프로덕션에 영향을 줌<ul>
<li>작은 분기를 하나 만들때마다 프로덕션에 큰 영향을 줄 수 있음</li>
<li>실제로 구현 가능한 것과 균형을 잡아야 함</li>
</ul>
</li>
<li>작가는 새로운 시각을 제공해줄수 있음</li>
</ul>
<h2 id="인터랙티브-스토리텔링의-미래">인터랙티브 스토리텔링의 미래</h2>
<ul>
<li>수동적이었던 청중은 점점 더 능동적이 되고싶어함</li>
<li>인터렉티브한 스토리텔링으로 전달되는 이야기는 미래에 더 늘어날 것임</li>
</ul>
<p>게임은 지속적으로 진화할 것</p>
<ul>
<li>더 의미있는 경험, 특히 액션 게임에서</li>
<li>각본, 연기, 시네마에 더 많은 관심</li>
</ul>
<p>조언?</p>
<ul>
<li>게임은 예술처럼 다루어져야 한다</li>
<li>전달하고자 하는 것을 찾아라</li>
<li>나만의 방식을 찾아야 한다</li>
<li>나만의 규칙을 세워야 한다</li>
</ul>
