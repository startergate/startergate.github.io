<h4>Django ORM의 특징</h4>
<ul>
<li>Lazy Loading</li>

<li>=&gt; QuerySet Caching 필요</li>

</ul>
<h4>QuerySet 상세</h4>
<ul>
<li>select_related와 prefetch_related</li>
<li>selected_related</li>
<li>조인으로 수행</li>
<li>=&gt; 즉시 로딩</li>
<li>prefetch_related</li>
<li>추가 SQL로 수행</li>
<li>전부 새로운 쿼리셋으로 실행</li>
<li>=&gt; 필드 하나당 쿼리 하나

<h3>실수하기 쉬운 QuerySet의 특성들</h3>
<ul>
<li>prefetch_related와 filter는 완전 별개의 쿼리 실행</li>
<li>메인 쿼리에서 Join하고 추가 쿼리에서 한번 더 조회</li>
<li><img src="https://raw.githubusercontent.com/startergate/Conferences/master/pycon-kr-2020/statics/3.png" alt="" loading="lazy" /></li>
<li>annotate =&gt; select_related =&gt; filter =&gt; prefetch_related</li>
<li>이 순서가 실제 SQL 실행 순서와 가장 유사</li>
<li>다른건 몰라도 prefetch_related는 filter 뒤에 두는게 낫다.</li>
<li>QuerySet 캐시를 재활용하지 못하는 queryset 호출</li>
<li>.all을 호출하고 list 문법 사용해서 사용해야</li>
<li><img src="https://raw.githubusercontent.com/startergate/Conferences/master/pycon-kr-2020/statics/4.png" alt="" loading="lazy" /></li>
<li>RawQuerySet (.raw) 은 NativeSQL이 아니다</li>
<li>여전히 prefetch_related(), Prefetch() 사용 가능</li>
<li>대신 아래의 내용은 사용 불가</li>
<li><img src="https://raw.githubusercontent.com/startergate/Conferences/master/pycon-kr-2020/statics/5.png" alt="" loading="lazy" /></li>
<li>서브 쿼리 발생 조건</li>
<li>QuerySet 안에 QuerySet이 있는 경우에 발생</li>
<li>QuerySet이 아니도록 만들어 해결</li>
<li>exclude를 역방향 참조 모델에 사용하는 경우에 발생</li>
<li>Join으로 풀리게 유도가 불가능</li>
<li>prefetch_related(Prefetch())를 사용하는 방식으로 대체</li>
<li>정방향에서는 정상 작동</li>
<li>QuerySet의 반환 타입</li>
<li><img src="https://raw.githubusercontent.com/startergate/Conferences/master/pycon-kr-2020/statics/6.png" alt="" loading="lazy" /></li>
<li>values(), values_list() 사용시 EagerLoading 무시</li>
<li>select_related, prefetch_related 전부 무시</li>
</ul>
