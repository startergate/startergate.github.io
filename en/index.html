01 — About

I'm a backend engineer.
I build what you don't see.

I build programs that run on servers, and the programs that connect to them.

Stack

I build with TypeScript on Node.js, mainly using NestJS as the server framework. I work with MySQL-family databases both through raw queries and TypeORM, and have run Aurora MySQL migrations and operations, Redis/DynamoDB caching, and task distribution combining RabbitMQ and SQS in production.

Experience

I've worked on everything from a backend serving 750K MAU to a crawling system handling 5M jobs a day, four-tier database clusters, and infrastructure and internal networking spanning cloud and on-premise. Across about 9 years of development and 5 years 3 months in industry, I've built frontend, infrastructure, and CI/CD alongside backend work, and designed the architecture for several projects.

Cloud & Ops

I ran AWS as the primary cloud, mixing in GCP and Naver Cloud Platform as cost and needs required. I built and ran CI/CD with GitHub Actions, deployment logic with the AWS SDK, and monitoring with Sentry and Grafana wired into Slack.

Collaboration

Beyond my own team, I've worked with MSPs like Bespin Global, partners like SmartRo, PortOne, and Naver Shopping, onboarded merchants, and public institutions — a wide range of external collaboration and API integrations.
